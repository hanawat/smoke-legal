プライバシーポリシー

最終更新日: 2026年10月8日

モクナビ（MOKUNAVI、以下「本アプリ」）は、ユーザーの皆さまのプライバシーを尊重します。 本ポリシーは、本アプリが取得・利用・保存する情報と、その取り扱いについて説明します。

1. 位置情報の利用

本アプリは、現在地周辺の喫煙所の表示、徒歩経路の案内、喫煙所の投稿・チェックイン時の 現地での滞在確認、およびチェックイン・投票(「吸えない」)への現在地の付与のために、 精密な位置情報(GPS)を使用します。

  • 位置情報の取得は、本アプリを使用している間のみ行います。バックグラウンドでの取得は行いません。
  • チェックイン・投票時の現在地は、スポットの利用状況や信頼度を算出する目的でバックエンドに送信・保存されます。
  • 位置情報へのアクセスは、端末の設定からいつでも変更できます。

2. アカウントとユーザー識別

本アプリは、最初の起動時に匿名のアカウントを自動で作成します。本名・メールアドレス・電話番号などの 個人を特定する情報は取得しません。投稿・チェックイン・投票・お気に入り・表示名・差し入れの記録は、このアカウントの ID (以下「匿名 ID」)に紐付けて管理されます。

  • 任意で「Apple でサインイン」を利用できます。Apple から受け取るのは、アカウントを識別するための ID だけです。氏名とメールアドレスは求めません。
  • Apple でサインインしたアカウントは、別の端末で同じ Apple ID でサインインすると復元できます。表示名と、ランキングで公開するかの設定も復元されます。
  • 復元のときに、その端末で匿名のまま使っていたデータを、Apple でサインインしたアカウントに引き継ぎます。チェックイン・投票・お気に入りとメモは引き継ぎ先のアカウントに移し、表示名と公開の設定は引き継ぎ先にまだなければ写し、差し入れの本数は引き継ぎ先のアカウントの分として数えます。投稿した喫煙所・写真・通報は元の匿名 ID のまま、引き継ぎ先のアカウントと結び付けて管理します。

3. ユーザー投稿コンテンツ

ユーザーが投稿した喫煙所の情報(名称・位置・住所・営業時間・設備・説明・写真)は、バックエンドに保存され、 他のユーザーから閲覧できる公開情報として共有されます。写真は1件につき3枚までで、 撮影位置などのメタデータは送信前に削除します。 チェックインのスポット・現在地・サーバーでの記録時刻、投票と投票時の現在地も、 匿名 ID とともに保存されます。個々のチェックインと投票は、ご本人のみが読めます。 チェックインは地点ごとの回数として吸えた率やランキングに、投票はスポットの信頼度の算出に使われます。 地点のランキングでは、第4節で名前を公開していない人を「匿名ユーザー」と表示します。 お気に入りのスポット ID とメモはバックエンドに保存され、ご本人のみがアクセスできます。 通報とブロックの内容(対象・理由・メモ)は匿名 ID とともに保存され、運営だけが確認します。 ほかのユーザーや投稿者には公開しません。

4. 表示名とランキングでの公開

設定のプロフィールで表示名を入れると、ランキングで公開するかの設定とともにバックエンドに保存し、 匿名 ID に紐付けて管理します。表示名の設定は任意です。 以前の版で端末にだけ保存していた表示名も、アップデートの後に非公開のままバックエンドに保存します。

  • 表示名がほかのユーザーに表示されるのは、設定の「ランキングで名前を公開」をオンにしたときだけです。初期設定はオフで、いつでもオフに戻せます。差し入れのあとに一度だけ、公開するかをおたずねします。
  • 公開すると、差し入れの累計の本数と、地点ごとのチェックインの回数(公開する前の分も含みます)が、その名前とともにランキングに表示されます。
  • 公開しない場合も、表示名はバックエンドに保存されますが、ほかのユーザーには表示しません。
  • 不適切な表現・URL・メールアドレスを含む名前は、保存の際に受け付けないことがあります。
  • 公開された名前は、ほかのユーザーが通報・ブロックできます。名前の通報では、確認のために通報の時点の名前を記録し、運営が確認します。運営は、利用規約に違反する名前を隠すことがあります。名前を 2 回隠されたアカウントは、運営が解除するまで、別の名前でも公開できません。
  • ランキングに写真や画像は表示しません。

5. 差し入れ(App 内課金)の記録

開発者への差し入れ(App 内課金)の支払いは Apple が処理します。本アプリは、カード番号などの支払いの情報を受け取りません。 差し入れの本数を正しく数えるため、次のとおり購入の記録を扱います。

  • 購入の際に、匿名 ID を Apple に渡し、取引の持ち主の確認に使います。
  • 取引ごとに、取引 ID・商品・本数・購入日時・環境(本番の購入かテストの購入か)・払い戻しや取り消しの有無を、匿名 ID とともにバックエンドに保存します。
  • 記録の内容は、Apple の App Store Server API に取引 ID で問い合わせて確かめます。払い戻しなどの Apple からの通知と、Apple の記録との照合によって記録を更新し、払い戻された差し入れは数えません。
  • 累計の本数はご本人に表示し、第4節で名前を公開したときだけ、ほかのユーザーにもランキングで表示します。個々の取引の記録は公開しません。

6. 端末内のみに保存される情報

プロフィール画像(アバター)、投稿前の下書きと写真は、お使いの端末内にのみ保存され、 サーバーへは送信しません。プロフィール画像は、ほかのユーザーにも表示しません。 ホーム画面のウィジェットに表示する保存済みのスポット情報も端末内で共有し、 現在地の座標はウィジェットと共有しません。

7. 第三者への提供・トラッキング

本アプリは、第三者によるトラッキング、広告、解析 SDK を一切使用しません。 取得した情報を第三者に販売することはありません。投稿・チェックイン・投票の公開範囲は第3節、 表示名の公開範囲は第4節のとおりです。差し入れの取引は、第5節のとおり Apple に問い合わせて確かめます。

8. 診断情報

アプリの品質改善のための診断情報(クラッシュ・ハングなどの記録)は、 MetricKit および OSLog を用いて端末内で扱われます。これらの診断情報を 外部へ自動送信することはありません。設定の診断データ画面で共有を選択した場合に限り、 選択した診断ファイルを端末の共有機能で書き出せます。

9. データの保存先と保護

バックエンドに送信される情報は、暗号化された通信を通じてクラウドの同期サービスに保存されます。 お気に入りとメモ、個々のチェックインと投票、差し入れの記録は、アクセス制御によりほかのユーザーには公開しません。 投稿した喫煙所は第3節、公開を選んだ表示名は第4節の範囲で公開されます。

10. データの削除・お問い合わせ

設定画面の「アカウントとデータを削除」から、いつでもアカウントとデータを削除できます。 削除すると、チェックイン・投票・お気に入りとメモ・投稿した喫煙所の説明と写真・表示名と公開の設定・ 差し入れの記録がバックエンドから削除され、あなたの名前はランキングに表示されなくなります。 端末内の下書き・未送信のデータ・表示名・プロフィール画像も削除されます。 投稿した喫煙所の名称・位置・住所・営業時間・設備などの場所情報は、投稿者と結び付かない形で 地図の情報として残ります。あなたが行った通報は、不適切な投稿への対応の記録として、 あなたと結び付かない形で残ります。

Apple でサインインしている場合は、削除の際に Apple で本人の確認を行い、本アプリと Apple ID との連携も 取り消します。第2節の引き継ぎで結び付けた匿名のアカウントのデータも、あわせて削除します。
