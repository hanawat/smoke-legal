プライバシーポリシー

最終更新日: 2026年9月27日

モクナビ（MOKUNAVI、以下「本アプリ」）は、ユーザーの皆さまのプライバシーを尊重します。 本ポリシーは、本アプリが取得・利用・保存する情報と、その取り扱いについて説明します。

1. 位置情報の利用

本アプリは、現在地周辺の喫煙所の表示、徒歩経路の案内、喫煙所の投稿・チェックイン時の 現地での滞在確認、およびチェックイン・投票(「吸えない」)への現在地の付与のために、 精密な位置情報(GPS)を使用します。

  • 位置情報の取得は、本アプリを使用している間のみ行います。バックグラウンドでの取得は行いません。
  • チェックイン・投票時の現在地は、スポットの利用状況や信頼度を算出する目的でバックエンドに送信・保存されます。
  • 位置情報へのアクセスは、端末の設定からいつでも変更できます。

2. 匿名認証とユーザー識別

本アプリは匿名認証を採用しており、氏名・メールアドレス・電話番号などの個人を特定する情報は 取得しません。匿名認証で発行される ID により、投稿・チェックイン・投票・お気に入りはこの匿名 ID に 紐付けて管理されます。

  • 別の端末への履歴の引き継ぎには対応していません。

3. ユーザー投稿コンテンツ

ユーザーが投稿した喫煙所の情報(名称・位置・住所・営業時間・設備・説明・写真)は、バックエンドに保存され、 他のユーザーから閲覧できる公開情報として共有されます。写真は1件につき3枚までで、 撮影位置などのメタデータは送信前に削除します。 チェックインのスポット・現在地・サーバーでの記録時刻、投票・コメント・投票時の現在地も、 匿名 ID とともに保存・公開されます。チェックインは吸えた率やランキングにも使われます。 お気に入りのスポット ID とメモはバックエンドに保存され、ご本人のみがアクセスできます。

4. 端末内のみに保存される情報

表示名とプロフィール画像(アバター)、投稿前の下書きと写真は、お使いの端末内にのみ保存され、 サーバーへは送信しません。ホーム画面のウィジェットに表示する保存済みのスポット情報も端末内で共有し、 現在地の座標はウィジェットと共有しません。

5. 第三者への提供・トラッキング

本アプリは、第三者によるトラッキング、広告、解析 SDK を一切使用しません。 取得した情報を第三者に販売することはありません。投稿・チェックイン・投票の公開範囲は第3節のとおりです。

6. 診断情報

アプリの品質改善のための診断情報(クラッシュ・ハングなどの記録)は、 MetricKit および OSLog を用いて端末内で扱われます。これらの診断情報を 外部へ自動送信することはありません。設定の診断データ画面で共有を選択した場合に限り、 選択した診断ファイルを端末の共有機能で書き出せます。

7. データの保存先と保護

バックエンドに送信される情報は、暗号化された通信を通じてクラウドの同期サービスに保存され、 お気に入りとメモはアクセス制御によりご本人のみがアクセスできます。投稿・チェックイン・投票は第3節の範囲で公開されます。

8. 外部データソース

公共の喫煙所情報の一部は、share-map.net(喫煙所 情報共有マップ)から取得しています。

9. データの削除・お問い合わせ

設定画面の「アカウントとデータを削除」から、いつでもアカウントとデータを削除できます。 削除すると、チェックイン・投票・お気に入りとメモ・投稿した喫煙所の説明と写真がバックエンドから削除され、 端末内の下書き・未送信のデータ・表示名・プロフィール画像も削除されます。 投稿した喫煙所の名称・位置・住所・営業時間・設備などの場所情報は、投稿者と結び付かない形で 地図の情報として残ります。

削除についてのご依頼や、本ポリシーに関するお問い合わせは、以下の窓口までご連絡ください。

10. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更されることがあります。重要な変更がある場合は、 本ページにて告知します。
